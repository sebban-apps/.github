# Sebban Apps

Proste aplikacje na co dzień, które można zainstalować na telefonie jak zwykłą aplikację (PWA).
Dane zapisują się na Twoim urządzeniu.

## Aplikacje

| Aplikacja | Do czego służy | Otwórz |
|---|---|---|
| **Dziennik** (Journal-PWA) | Prosty timer do nauki | [otwórz](https://sebban-apps.github.io/Journal-PWA/) |
| **Dziennik treningowy** (training-log) | Zapisywanie treningów i postępów | [otwórz](https://sebban-apps.github.io/training-log/) |
| **Kalendarz** (Calendar-PWA) | Prosty kalendarz z wydarzeniami | [otwórz](https://sebban-apps.github.io/Calendar-PWA/) |

## Jak zainstalować na telefonie?

1. Otwórz link do aplikacji w przeglądarce na telefonie.
2. Na Androidzie w Chrome otwórz menu (trzy kropki) i wybierz „Dodaj do ekranu głównego”.
3. Na iPhonie w Safari naciśnij przycisk Udostępnij i wybierz „Do ekranu początkowego”.

Szczegółowa instrukcja każdej aplikacji jest w pliku README w jej repozytorium.
